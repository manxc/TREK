# TREK 简体中文 / English 家庭协同版

这个 fork 基于 TREK v3.4.1，保留英文界面并将简体中文设为家庭部署的默认语言。每位用户仍可在登录页或“设置 → 通用”中随时切换语言。

本分支面向一个具体场景：两家共 6 人（4 位成人、2 位儿童）分别从两座城市出发，在同一目的地汇合，进行 4 天 3 晚的当地旅行。

## 已完成的适配

- 简体中文为未登录用户和新用户的默认语言，英文可随时切换。
- 采用源代码构建镜像，不跟随可变的 `latest` 镜像。
- 容器仅监听本机回环地址，通过 Cloudflare Tunnel 提供 HTTPS；家庭路由器无需开放端口。
- 数据库与上传文件独立持久化，升级镜像不会覆盖旅行资料。
- 默认关闭第三方插件运行时，保留行程、地图、预算、行李清单、文件和实时协作等核心功能。
- 运行与开发依赖已升级，并通过完整的 `npm audit` 检查。

部署文件和操作步骤见 [家庭旅行部署指南](deploy/family-trip/README.md)。

## 推荐的 6 人协作方式

1. 由一位成人担任行程所有者和站点管理员。
2. 其余 3 位成人各自注册账户，便于实时编辑、投票和查看任务。
3. 两位儿童作为行程“访客”加入；访客无需账户，但可参与费用分摊、行李清单、任务和当天活动。
4. 分别创建两条抵达交通记录，表示家庭 A、家庭 B 从不同城市出发并在目的地汇合。
5. 行程日期按目的地当地日期设置为连续 4 天；住宿设置为入住首日、退房第 4 天，共 3 晚。

## 隐私建议

- 邀请成人使用后台生成的限次、限时注册链接，并直接绑定到本次行程。
- 注册完成后关闭开放注册，撤销未使用的邀请链接。
- 不要创建包含预算或预订信息的匿名公开分享链接。
- 管理员开启 MFA，并启用每日自动备份；加密密钥单独保存到密码管理器。
